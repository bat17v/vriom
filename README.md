# Vriom

Минималистичный нативный текстовый редактор под Linux для работы над художественными книгами и длинными текстами. Построен на идее модульного редактирования: снаружи это единый открытый файл проекта под контролем Git, внутри — гибкий конструктор из независимых абзацев.

## Философия

* **Zero UI по умолчанию:** Никаких лишних панелей, кнопок и рамок, пока они не понадобятся. Если у абзаца нет альтернативных версий — вокруг него нет элементов управления.
* **Никакой навязанной бюрократии:** Никаких встроенных «анкет персонажей» и жестких схем мироустройства. Только текст и свободные заметки рядом.
* **Независимость от редактора:** Вся книга вместе с заметками хранится в едином открытом стандартизированном файле со своим расширением. Если редактор перестанет существовать, исходники легко читаются и разбираются без потерь в любом текстовом просмотре.

## Ключевые возможности

### 1. Модульная структура и состояния абзацев
Базовым кирпичиком текста выступает отдельный абзац (или структурный блок главы). Каждый абзац имеет:
* **Цветовую дифференциацию фрагментов:** Абзацы и отрезки текста визуально отделяются друг от друга цветом, чтобы глаз легко считывал границы кусков в сплошном потоке.
* **Три состояния жизненного цикла:**
  * **Чистовик** — основной художественный текст, попадающий в финальную сборку.
  * **Синопсис** — краткий план или инженерная заметка о том, что должно произойти в этом месте (визуально отличается от основного текста и игнорируется при экспорте).
  * **Скрытый (в стол)** — абзац схлопывается в тонкую линию на полях. Не удаляется, не мешает чтению сцены, но разворачивается в любой момент.
* **Локальное ветвление версий (A/B варианты):** Возможность хранить несколько вариантов одного абзаца прямо на месте и переключаться между ними. Индикатор версий (`1/2`) появляется только тогда, когда вариантов больше одного.
* **Блоки глав:** Специальные структурные разделители, позволяющие отбивать начала глав, видеть структуру и сворачивать главы целиком.

### 2. Два режима работы
* **Режим письма (Write Mode):** Бесшовный ввод текста с клавиатуры, как в обычном редакторе.
  * **Немигающий курсор** для снижения визуального шума при долгой работе.
  * **Фокус-затенение:** Весь текст вокруг текущего активного абзаца приглушается в мягкий полутон.
  * **Автотипографика на лету:** Автоматическая замена `--` на длинное тире (`—`), корректная расстановка кавычек-«ёлочек» и типографских символов при вводе.
* **Режим обзора и монтажа (Overview Mode):** Мгновенное переключение в режим работы со структурой.
  * Выделение произвольных диапазонов абзацев через `Shift + Стрелки` (или мышью).
  * Перетаскивание выделенных кусков текста и целых сцен по документу.
  * Массовое изменение состояния (например, перевод группы абзацев в синопсис или скрытые).

### 3. Боковая панель заметок
* Скрываемая по одному хоткею боковая панель для рабочих мыслей, деталей мира и черновых набросков.
* Построена на том же блочном движке: заметки можно визуально разделять цветом, сворачивать, перетаскивать с `Shift` для упорядочивания и переносить прямо в основной текст книги (и обратно).

### 4. Хранение и контроль версий
* **Единый файл проекта:** Основной текст книги и боковые заметки хранятся в одном человекочитаемом текстовом файле с собственным расширением и открытым форматом разметки.
* **Автономный Git:** Автоматическая фиксация истории изменений в локальном `.git` репозитории без необходимости в сервере или подключении к сети.

## Стек и сборка (NixOS)

Проект написан на нативном **OCaml** с использованием **SDL2**.

Для запуска окружения разработки через Nix Flakes:

```bash
nix develop
dune build
```
